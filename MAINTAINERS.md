# Maintainers and release roles

## Bootstrap owners

| Role | Owner | State |
| --- | --- | --- |
| Repository steward | `@777genius` | Active |
| Normative maintainer | `@777genius` | Active for draft incubation |
| Security responder | `@777genius` | Active for draft incubation |
| Independent conformance maintainer | Unassigned | Blocks public prerelease |
| Release maintainer | Unassigned | Blocks public prerelease |

The table is intentionally honest: this repository does not yet have independent
organizational stewardship. A public RC requires at least one additional named
human so the author of a semantic change cannot also supply its only
conformance approval and release approval.

Role changes are reviewed pull requests. Removing the last security responder,
normative maintainer, or release maintainer blocks publication until ownership is
restored. Credentials are never listed here; release evidence records only the
approved GitHub actor and protected environment identity.
