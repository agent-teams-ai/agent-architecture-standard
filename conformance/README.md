# Independent conformance skeleton

This unpublished Phase 1 workspace-data skeleton consumes the checked-in
normative artifact manifest and language-neutral vectors directly from the
source workspace. It does not inspect an npm tarball, install a package, import `lib/`,
generated runtime codecs, a reference provider, or Foundation code. It is not a
conformance claim or an independent-oracle qualification.

This directory currently verifies only artifact digests. A separately reviewed
black-box runner and independently authored expectations are still required
before this skeleton can produce conformance evidence.
