# Support and compatibility

This repository is experimental until a release explicitly says otherwise.
Use GitHub issues for public questions and proposals; use private vulnerability
reporting for security issues.

Prereleases use `-rc.N` and a non-`latest` package tag. They may change within
the documented 0.x compatibility policy, but their bytes, identifiers, and
release manifests are immutable. A numeric 0.x is separately qualified; an RC
is never silently promoted or retagged as stable.

Every conformance claim names the exact standard, profile, suite, artifact, and
evidence versions. A bare claim of "AAS compliant" is invalid.
